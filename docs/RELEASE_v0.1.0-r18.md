# R18 短信接入候选（未发布）

在已验证 R17 一体音频基础上，把 MU300 原生短信库接入 AirSIM 客户端的现有接口：收件箱、变化通知、保存确认和发送。无需修改客户端，也不改变系统、内核或音频组件。

手机确认保存后仅记录交付标识，保留设备原短信；发送走系统原生 PDU 工具。增加并发保护、两分钟重复提交保护，以及超时/中断时明确报告结果未知、不自动重发。原生短信正文不额外写入 Agent 日志或持久化状态。

候选范围仍为已验证的 U30 Air / `5.4.254-gb50db5b6224c` 音频配置，不覆盖 F50 / 7.2.8。历史 R16 面向 1031 之后版本线、R12 面向 1031 之前版本线；日期不等于硬件兼容证明。

模拟测试已经覆盖协议、鉴权、交付持久化及发送异常；真实短信收发、后台推送与云端路径尚未验收，不发布为已验证功能。详见 [短信接入说明](AIRSIM_SMS.md)。
